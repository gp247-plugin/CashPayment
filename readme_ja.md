### 1. 概要
GP247/Shop 向けの現金払い（Cash payment）プラグインです。商品お届け時に現金で代金を受け取る、またはオフラインで支払いを行う運用に適しています。注文は正常に作成され、支払いはシステムの外で購入者と販売者の間で行われます。

### 2. 機能紹介
- チェックアウトの流れに「代金引換（現金払い）」の支払い方法を追加します。
- オンライン決済は処理しません。代金を受け取るまで、注文は支払い待ちの状態になります。
- 管理画面で有効化／無効化できます。
- コアのバージョン 1.1 以降に対応し、`gp247/shop` パッケージを使用します。

### 3. インストール方法
次のいずれかの方法でインストールできます。

1) オンラインインストール：管理画面のプラグインライブラリを開き、「Cash payment」を検索してインストールします。
2) ZIP ファイルからのインストール：管理画面からプラグインの ZIP パッケージをアップロードします。
3) 手動インストール：解凍して `app/GP247/Plugins/CashPayment` フォルダーにコピーし、管理画面でローカル設定の保存を実行します。

拡張機能のインストールガイド（英語）：`https://gp247.net/en/docs/user-guide-extension/guide-to-installing-the-extension.html`

#### コマンドラインでのインストール（CLI、gp247 3.x）

gp247 3.x からは、管理画面を開かずに、GP247 ライブラリから **CashPayment** をダウンロードしてコマンドラインですぐにインストールできます。このプラグインには、サイトに `gp247/shop` パッケージがインストールされている必要があります。サイトのルートフォルダーでターミナルを開き、次を実行します。

```bash
# 1) ウェブサイトごとに 1 回だけ：GP247 ライブラリに接続するための API License（無料）を登録
php artisan gp247:ext-register-license

# 2) ライブラリからプラグインをダウンロードしてインストール
php artisan gp247:ext-install --type=plugin --key=CashPayment
```

- 手順 1 の前に、`.env` の `APP_URL` がサイトの**実際のドメイン**になっていることを確認してください（`http://localhost` のままにしないでください）。ライセンスはこのドメインに紐づけられます。
- インストールが完了すると、プラグインは**有効化済み**の状態になり、キャッシュも自動で更新されます。管理画面で追加の操作は必要ありません。
- コマンドは `gp247.json` で宣言された条件（コアのバージョン、composer パッケージ、依存プラグイン）を自動でチェックします。不足があればコマンドは停止し、何が足りないかを明示します（例：サイトにまだ `gp247/shop` がない）。
- `app/GP247/Plugins/CashPayment` フォルダーがすでにサーバー上にある場合（手動でコピーした、またはインストールパッケージに同梱されていた場合）、コマンドは再ダウンロードせず**その場でインストール**します。
- プラグインがすでにインストール済みの場合、コマンドは実行を拒否します。新しいバージョンに更新するには `php artisan gp247:ext-update --type=plugin --key=CashPayment` を実行します。
- コマンドの末尾に `--json` を付けると、機械可読な形式で結果を受け取れます（スクリプト／CI 用）。
- 詳細：[プラグイン＆テンプレートのインストールガイド](https://github.com/gp247net/gp247-docs/blob/main/extension/install-extension.md) · [コマンドリファレンス](https://github.com/gp247net/gp247-docs/blob/main/system/command-line-reference.md)。

### 4. 使い方
- 管理画面：Plugins → Payment で「Cash payment」を有効にします。
- この支払い方法には追加の設定は不要です。
- ストアのチェックアウト画面で、購入者が「代金引換（現金払い）」を選択します。
- 代金の受領が確認されるまで、注文は支払い待ちの状態で表示されます。
